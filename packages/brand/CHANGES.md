# Changelog

## 1.0.0 10-11-2026

- First release.
- Outfit variable font (OFL-1.1) bundled with `fonts.css`, covering the
  latin and latin-ext subsets, with no external font service dependency.
- Som Energia logo (`logos/logo.svg`).
- Favicons: ICO, SVG and PNG sizes for browsers, Apple and Android.
- Licensing: AGPL-3.0-only for package-authored CSS and documentation,
  restricted usage terms for logos and favicons (`LICENSE-LOGO`).
- Logo variants for dark backgrounds (`logos/logo-dark.svg`) and for
  inline use that inherits the CSS color (`logos/logo-mono.svg`).
